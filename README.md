# Sistem Informasi & Web Sekolah (SD / SMP / SMA)

Aplikasi web sekolah berbasis **PHP 8.2**, **MySQL 8.0**, dan **Docker**.

## Fitur Utama
- **Portal Publik:** Informasi profil sekolah dan papan pengumuman (Umum, Akademik, Prestasi).
- **PPDB Online:** Pendaftaran siswa baru untuk jenjang SD, SMP, dan SMA.
- **Dashboard Admin:** Manajemen pengumuman dan verifikasi status pendaftar PPDB.

## Cara Menjalankan Project
1. Pastikan **Docker** dan **Docker Compose** sudah terinstal.
2. Jalankan perintah berikut di terminal:
   ```bash
   docker-compose up -d --build
